说明 · 「流转中」和「当前使用」不是一回事

它们是两个独立的标记，同一版可以只占其中一个。

流转中　= 这一版铸出的记录正在走 已确认 → 已下单 → 准备排货 → 已排货 → 已完结。 采购与排货消费的是它：组单、排货看到的需求都来自这一版的记录。

当前使用　= 计算需求时读的是哪一版，默认是最新那一版。它决定「算出来的数」， 不决定「谁在跑」。

发货前按「当前使用」算，发货后快照冻结。 否则：货已经发出去了，有人又把「当前使用」切到别的版， 于是这批货的计算依据在事后被改掉了 —— 单据还在，依据却对不上，追溯就断在这里。

「内容摘要」在本原型的 store 里叫 digest（真实系统的字段名是 content_digest）—— 同样的内容得到同样的摘要，用来回答「这两版到底是不是一份东西」。 点行展开可看这一版冻结了哪些格子的什么值。

表里的「记录数」是真实存在的记录，不是 rev.line_ids 的长度 —— 两者对不上时上面会有横幅点名。rev 冻结的是「计划采购量」（铸出记录的 total）； 销量预估、库存推演都不随 rev 冻结，它们跟着当前数据走。
